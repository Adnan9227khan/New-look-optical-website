# New Look Opticals - Admin Panel Guide

## 📱 How to Update Frames Daily

### Step 1: Access Admin Panel
1. Go to: `your-website-url/admin/login`
2. Login with credentials:
   - **Username:** admin
   - **Password:** admin123

### Step 2: Add New Frame
1. Click the **"Add New Frame"** button
2. Fill in the form:
   - **Frame Name**: e.g., "Ray-Ban Aviator Gold"
   - **Category**: Choose from:
     - Men's Frames
     - Women's Frames
     - Kids Collection
     - Contact Lenses
     - Sunglasses
   - **Price**: Enter price in rupees (e.g., 2999)
   - **Brand**: Optional (e.g., Ray-Ban, Oakley)
   - **Image URL**: Get free images from:
     - [Unsplash](https://unsplash.com) - Search for eyeglasses
     - [Pexels](https://pexels.com) - Search for frames
     - Right-click image → Copy image address
   - **Description**: Brief description (optional)
   - **In Stock**: Check if available

3. Click **"Add Frame"** button

### Step 3: Edit Existing Frame
1. Find the frame card in the dashboard
2. Click **"Edit"** button
3. Update the information
4. Click **"Update Frame"**

### Step 4: Delete Frame
1. Find the frame card
2. Click **"Delete"** button
3. Confirm deletion

## 🔐 Security Tips

1. **Change Default Password**:
   - After first login, create a new admin user with a strong password
   - Ask your developer to remove the old admin account

2. **Keep Credentials Safe**:
   - Don't share admin login details
   - Use a strong password

3. **Regular Updates**:
   - Update frames regularly to show latest inventory
   - Remove out-of-stock items or mark them as "Out of Stock"

## 📸 Finding Good Images

### Best Practices:
1. **Search Terms**:
   - "eyeglasses frames"
   - "sunglasses product"
   - "optical glasses"
   - Brand name + "frames"

2. **Image Quality**:
   - Use high-resolution images
   - White/clean background looks professional
   - Show frame clearly from front view

3. **Getting Image URL**:
   - Search on Unsplash/Pexels
   - Click on image you like
   - Right-click → "Copy image address"
   - Paste in "Image URL" field

## 🆘 Troubleshooting

**Problem**: Can't login
- Solution: Check username and password (case-sensitive)
- Contact: Your developer if still issues

**Problem**: Image not showing
- Solution: Make sure URL starts with `https://`
- Try a different image URL

**Problem**: Changes not appearing on website
- Solution: Refresh the website (Ctrl+F5 or Cmd+Shift+R)
