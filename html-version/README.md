## 📝 Customization Guide

### Change Contact Information
In the HTML file, find and replace:
- **Phone**: `+919173355559` → Your phone number
- **Email**: `newlookopticals5555@gmail.com` → Your email
- **Address**: Update address text
- **Instagram**: `newlookopticals55559` → Your handle

### Change Colors
In `style.css`, update the CSS variables:
```css
:root {
    --blue-600: #2563eb;  /* Main blue color */
    --green-500: #22c55e; /* WhatsApp green */
    --slate-900: #0f172a; /* Dark color */
}
```

### Add/Remove Sections
Simply copy-paste section blocks in HTML:
```html
<section class="section">
    <div class="container">
        <!-- Your content here -->
    </div>
</section>
```

### Change Images
Replace image URLs in the products section:
```html
<img src="YOUR-IMAGE-URL-HERE" alt="Description">
```

Get free images from:
- [Unsplash](https://unsplash.com)
- [Pexels](https://pexels.com)
